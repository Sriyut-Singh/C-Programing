# Intermediate C Programming

Welcome to the **Intermediate** section of my C Programming learning journey!

This folder contains practical C programs covering important intermediate concepts, including arrays, strings, functions, pointers, structures, memory management, and file handling.

## Topics Covered

| No. | Program | Concepts Covered |
|---|---|---|
| 1 | Arrays.c | Array declaration, input, traversal, sum, average, minimum and maximum |
| 2 | Two_Dimensional_Arrays.c | 2D arrays, matrices, row sums and column sums |
| 3 | Strings.c | String input, length, vowels, consonants, digits and spaces |
| 4 | String_Functions.c | strlen(), strcpy(), strcat(), strcmp() and strchr() |
| 5 | Functions.c | Function declaration, definition, arguments and return values |
| 6 | Recursion.c | Factorial, Fibonacci series, digit sum and recursive printing |
| 7 | Pointers.c | Memory addresses, dereferencing, pointer modification and swapping |
| 8 | Pointer_Arithmetic.c | Pointer increment, decrement, addition, subtraction and array traversal |
| 9 | Structures.c | Structure declaration, members, functions and student records |
| 10 | Unions.c | Union declaration, shared memory and comparison with structures |
| 11 | Dynamic_Memory_Allocation.c | malloc(), calloc(), realloc() and free() |
| 12 | File_Handling.c | File creation, reading, writing, appending and closing |

## Learning Objectives

Through these programs, I aim to understand:

- How arrays and strings store and manage data.
- How functions improve code reusability and organisation.
- How recursion solves problems through repeated function calls.
- How pointers interact with memory addresses.
- How structures and unions organise different types of data.
- How dynamic memory allocation works.
- How files can be created, read, modified and managed using C.

## Compilation

These programs use standard C and can be compiled using GCC.

Example:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic Arrays.c -o Arrays
```

## Automated Compilation

This repository uses **GitHub Actions** to automatically compile C programs whenever relevant changes are pushed.

The workflow checks compilation using GCC with C11 and warning flags.
